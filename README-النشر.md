# نشر ساحة سيف مع الخادم المشترك (Netlify)

بهذا النشر تتجمع نتائج **الشاشتين وجوالات الزوار** في لوحة صدارة واحدة وتقرير واحد عند الأدمن (مثل خادم مدار تمامًا، لكن على Netlify مجانًا).

> السحب والإفلات (Netlify Drop) لا يشغّل الدوال، لذلك يلزم الرفع عبر GitHub أو Netlify CLI. إن رفعت الموقع بالسحب والإفلات يعمل كاملًا لكن في **وضع محلي** (كل جهاز يحفظ نتائجه وحده).

## الطريقة 1: عبر GitHub (الأسهل والأفضل)
1. أنشئ مستودعًا جديدًا في GitHub وارفع محتويات هذا المجلد كما هو (مجلدات `public` و`netlify` وملفا `netlify.toml` و`package.json`).
   ```
   git init && git add . && git commit -m "Saif Arena" 
   git branch -M main && git remote add origin https://github.com/<حسابك>/saif-arena.git && git push -u origin main
   ```
2. في Netlify: Add new site ← Import an existing project ← GitHub ← اختر المستودع. اترك Build command فارغًا، وسيقرأ الباقي من `netlify.toml`. اضغط Deploy.
3. (مهم) غيّر رمز الأدمن: Site configuration ← Environment variables ← أضف `ADMIN_PIN` بقيمة رقمك السري، ثم أعد النشر. الافتراضي `2026`.

## الطريقة 2: Netlify CLI (من جهازك)
```
npm i -g netlify-cli
netlify login
netlify deploy --build --prod
```

## بعد النشر
- افتح `https://موقعك/#admin` وادخل بالرمز. يجب أن ترى «متصل بالخادم المشترك».
- من الأدمن: اكتب **الرابط العام** (رابط موقعك) واحفظه، فيظهر في رموز QR.
- الشاشة الأولى: `https://موقعك/?kiosk=1#s1`، الشاشة الثانية: `https://موقعك/?kiosk=1#s2` (أو من أزرار «افتح الشاشة» في الأدمن).
- **وضع الزحمة:** في الأدمن فعّل المفتاح، فيظهر QR تحت لوحة الصدارة في الشاشتين ليلعب الزوار من جوالاتهم ويظهرون في اللوحة نفسها. أوقفه حين يخف الزحام.
- أرقام الجوالات لا تظهر في لوحة الصدارة ولا لأي زائر، وتظهر للأدمن فقط بعد إدخال الرمز.

## ملاحظات
- التخزين: Netlify Blobs (مجاني ضمن حدود Netlify الاعتيادية، ويكفي فعالية بآلاف الجولات).
- إن انقطع الإنترنت عن جهاز، تُحفظ جولاته عنده وتُرسل تلقائيًا عند عودة الاتصال.
- لتجربة محلية قبل النشر: `node devserver.mjs` ثم افتح `http://localhost:4300` (خادم تجريبي بالذاكرة فقط).

## المجسّم ثلاثي الأبعاد (تجربة محلل البيانات)
- الملف الجاهز: `public/js/expo3d.js` (مبني مسبقًا، لا تحتاج شيئًا للنشر).
- المصدر: مجلد `expo-src/src`، ولإعادة البناء: `sh expo-src/build.sh`.
- لو جهاز اللاعب لا يدعم WebGL تعمل التجربة تلقائيًا بالنسخة المسطحة القديمة.
