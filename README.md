# تجارب طويق التفاعلية (ساحة سيف)

منصة تجارب تفاعلية في الأمن السيبراني والذكاء الاصطناعي والبيانات: 13 تجربة على شاشتين، ولوحة صدارة، ولوحة إدارة، ووضع عرض (كيوسك)، وكوين يحمّله المشارك من الجوال. عربي افتراضيًا مع نسخة إنقلش.

## العمليات (صورة واحدة، أوامر مختلفة)
| العملية | الأمر | ملاحظات |
|---|---|---|
| ويب | `node src/main.mjs` (الافتراضي في الصورة) | يخدم الواجهة و`/api/*` |
| هجرة | `node src/migrate.mjs` | يُشغَّل قبل النسخة الجديدة ثم ينتهي |

لا يوجد worker ولا scheduler.

## المنفذ ومسارات الصحة
- المنفذ: `PORT` (الافتراضي `8080`)، على `0.0.0.0`.
- `GET /livez`: 200 ما دامت العملية حية، ولا يفحص أي اعتمادية.
- `GET /readyz`: 200 عند الجاهزية، و503 بعد بدء الإيقاف (`SIGTERM`)، ولا يفحص قاعدة البيانات.
- إيقاف تدريجي: عند `SIGTERM` تفشل `/readyz` وتُكمل الطلبات الجارية خلال `SHUTDOWN_GRACE_SECONDS` (25) ثم تخرج.

## الإعداد (متغيرات البيئة فقط)
كلها مشروحة في `.env.example`. أهمها: `ADMIN_PIN` (إلزامي، 6 خانات فأكثر، لا قيمة افتراضية)، `DATABASE_URL` (أو `DB_*`)، `DB_POOL_MAX`، `DB_SSLMODE`، `APP_URL`، `NODE_ENV`، `S3_*`، `RUN_MIGRATIONS`.
لا ملف `.env` في الحاوية، وتغيّر الإعدادات بعد إعادة التشغيل. لا توجد متغيرات تُدمج وقت البناء في الواجهة.

## قاعدة البيانات
- PostgreSQL فقط، والمستخدم غير superuser ويملك جداوله.
- **لا حاجة لأي امتداد (extension).**
- الهجرات: `migrations/*.sql` عبر أمر الهجرة، آمنة التكرار، وكل ملف داخل معاملة، ويحميها قفل advisory واحد على اتصال جلسة مخصص. `MIGRATION_DATABASE_URL` اختياري ليتجاوز PgBouncer.
- بوقت الإقلاع: `RUN_MIGRATIONS=true` (الافتراضي false) يشغّلها بنفس القفل.
- الجدول `app_data` فيه وثيقة JSONB واحدة. الطلبات لا تعتمد على حالة الجلسة، فتعمل خلف PgBouncer في وضع المعاملات.

## الموشن (التخزين المتوافق مع S3)
الفيديو الكبير (`saif-loader.mp4` نحو 14 ميجا) ليس في الصورة. يُرفع مرة واحدة:
```
S3_BUCKET=... S3_ACCESS_KEY_ID=... S3_SECRET_ACCESS_KEY=... S3_ENDPOINT=... npm run upload-assets -- ./saif-loader.mp4 video/saif-loader.mp4
```
ثم يُضبط `S3_PUBLIC_URL` على الرابط العام للحاوية فيحوّل التطبيق `/video/*.mp4` إليه. وإذا لم يتوفر، تتخطى الواجهة شاشة الانتظار بهدوء.
الملف الأصلي يسلّمه صاحب المشروع (غير مضمَّن في المستودع).

## التشغيل المحلي
```
docker compose up --build        # http://localhost:8080 ، رمز الإدارة: local-admin-pin
npm ci && npm test               # الاختبارات
```

## النشر
CI (`.github/workflows/docker.yml`) يبني الصورة في طلبات الدمج، ويبني ويدفع عند الدفع إلى `main` (اسم الصورة `saif-arena`) أو `staging` (اسم الصورة `stg-saif-arena`) بوسم `1.YYYYMMDDHHMMSS` بتوقيت UTC.
المنصة خلف Cloudflare وingress المنصة: الحاوية تخدم HTTP عاديًا ولا تحتوي بروكسي.

## الخصوصية
التسجيل بالاسم فقط، ولا تُجمع أرقام جوالات أو أي بيانات تواصل.
